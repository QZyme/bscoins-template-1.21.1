# 北山币 BS Coins

> NeoForge 1.21.1 的粉丝整活 + 模组开发辅助工具包 —— 一枚能弹射出去、能打赏、能把怪物打晕的硬币。

| 项目 | 说明 |
|---|---|
| 支持版本 | Minecraft **1.21.1** / NeoForge **21.1.248+** |
| 环境 | 客户端与服务端都需安装 |
| 可选依赖 | [帕秋莉手册 Patchouli](https://modrinth.com/mod/patchouli)（1.21.1-93-NEOFORGE 及以上）：装上后多一本《北山币指南》 |

## 安装

1. 给 1.21.1 客户端/服务端装好 **NeoForge 21.1.248 或更高**；
2. 把 `bscoins-<版本>.jar` 丢进 `mods/`；
3. （可选）同时放入 Patchouli，即可用 **书 + 北山币** 合成《北山币指南》。

不装 Patchouli 也完全可用：说明书相关的数据包文件、配方都是惰性的，不会报错刷日志。

## 快速上手

| 部件 | 合成 | 作用 |
|---|---|---|
| 点赞 | 红石 + 纸 | 右键：半径 8 格内玩家获得 8 秒鸡血，头顶冒红心（冷却 20 秒） |
| 投币 | 绿宝石 + 铁锭 | 右键：50/50 掷硬币，正面幸运 / 反面霉运各 60 秒（冷却 2 秒，不消耗物品） |
| 收藏 | 书与笔 + 末影珍珠 | 右键方块记录坐标；潜行右键查看收藏夹（上限 16 个） |

三者无序合成 → **北山币**（堆叠 64，达成成就「三连支持」）；北山币 + 下界之星 → **开发版北山币**。

## 北山币能做什么

- **右键玩家**：打赏 —— 鸡血（攻击 +4、攻速 +40%）+ 老板（最大生命 +6、护甲 +4），30 秒
- **右键怪物**：50% 眩晕 5 秒（完全定身）/ 50% 内讧（附近同类互殴）
- **右键村民**：消耗 1 枚币换**永久 8 折**（20% off，之后重开交易界面自动重贴、不再收费）
- **长按右键 3 秒**：生成北山团建圈（半径 10 格、10 分钟，作物加速 + 额外经验）
- **Q / V 键**：弹射投币（见下）
- **潜行 + Q**：一键搭测试场地（脚下一层 20×20 平台 + 面前一个测试假人，合计 1 枚币）
- **G 键 / 潜行右键空气**：打开北山开发助手

## 投掷手感（Q / V）

- **出手音效 + 翻滚**：扔出去有破空声；币在飞行中绕飞行轴翻滚（起始角度每枚不同），不再像一张贴在屏幕上的静止贴图
- **拖尾**：飞行时按速率铺一串电火花（**开发版北山币**是白色微光），一眼看清弹道；插在地上的币每 2 秒冒一颗微光，掉进草丛也能找回来
- 初速 **9 格/tick**，之后每 tick 乘 0.97 的空气阻力 → 出手最快、越飞越慢
- 重力 **0.055 格/tick²**，末端下坠速度约 **1.8 格/tick**：平抛约 **65 格、0.4 秒**落地；仰角 5°~45° 打到 130 格上限就烧毁（1~2 秒），不会再有"高抛飘十几秒"的情况
- **伤害按命中瞬间的速率线性缩放**：贴脸约 **12** 点、20 格约 **11** 点、60 格约 **10** 点（配置里三项都改过的话按你自己那套算）
- 击中生物有**撞击声 + 火花**，并沿飞行方向把目标**击退**（速率越快推得越远）
- 撞方块**像箭一样插住**不再弹跳，停稳 0.5 秒后主人走到 **1.5 格**内才会被吸回背包（拾回时有音效，绝不吞币）
- 投掷冷却 **0.4 秒**，就是物品栏上那圈白色冷却动画（`throwCooldownTicks`，0 = 可连发）
- 普通币水平射程超过 **130 格**会当场烧毁；**开发版北山币**射程无限、永不烧毁，飞满 120 秒变成掉落物

## 道具一览

| 道具 | 效果 |
|---|---|
| 催更大喇叭 | 朝视线方向喊出 **扇形**（±45°、32 格）：号角 + 音浪粒子，扇形内玩家收到催更消息并获 20 秒鸡血，冷却 5 秒 |
| 鸽子诱捕器 | 放出 5 只活鸽子（伞形飞散 + 白烟 + 咕咕叫），走远会像普通生物一样自然消失 |
| 基建狂魔镐 | 非潜行挖掘带出 3×3 平面（按视线朝向决定平面）；潜行只挖一格；进 `#minecraft:pickaxes`，可正常附魔 效率/时运/精准采集/耐久/经验修补 |
| 北山签名照 | 举起来「拍照」：闪光 + 火星 + 快门音效，16 格内玩家收到被闪到的消息 |
| NBT 查看器 | 右键方块/生物把 NBT 打到聊天栏 |
| 结构空投 | **看得见的箱子**（原版箱子模型，1 格大小）从 40 格高空以 0.15 格/tick 缓降（约 13 秒，缓慢自转 + 左右摇摆 + 云粒子）+ 升空信号弹；落地成战利品箱（正面朝向你）并通知坐标。箱内是原版地牢战利品 + **约 22% 概率**开出一件北山币系列道具（`bscoins:bs_coin` 最常出，开发版北山币约 0.4%），可自行编辑 `data/bscoins/loot_table/airdrop.json` |
| 《北山催更函》 | 连续 5 个 MC 天没用币就会被跟着：缓慢减速 + 头顶鸽子粒子，用掉一枚币解除 |
| 测试假人 | 100 血 + Boss 血条倒计时（默认 60 秒），被打时头顶飘**伤害数字**（显示实际掉血，致命一击标红） |

## 配置

- 游戏内：**模组列表 → BS Coins → 配置**（按功能分成 11 个小节，73 项都有中英双语标题 + 中文悬停说明）
- 文件：`config/bscoins-common.toml`（73 项，全部有中文说明）

常改的几项：`particleCount`（手持粒子数量）、`throwSpeed` / `throwGravity` / `throwDrag` / `throwBurnDistance` / `throwCooldownTicks` / `throwTrail`（投掷手感）、
`goadLevel` / `bossLevel`（Buff 等级）、`shopPrice*`（小卖部价格）、`enable*`（各功能开关）。

## 从源码构建

```bash
./gradlew build          # 产物: build/libs/bscoins-<版本>.jar
./gradlew runClient      # 开发环境启动客户端
./gradlew runData        # 生成数据（本模组目前为手写数据，可选）
```

> 需要 **JDK 21**。可选依赖 Patchouli 会在构建时从 `https://maven.blamejared.com` 解析；
> 如果网络到不了该仓库，把那行 `implementation` 注释掉，手动把 Patchouli 的 jar 放进 `run/mods/` 也能测试。

## 兼容性 / 已知限制

- 「北山小卖部替换流浪商人」会和其它改流浪商人的模组冲突，可用 `enableShop = false` 关闭
- 开发助手 GUI、测试平台/假人属于调试功能，正式服务器可按需关闭（`enableDevAssistant` / `enableTestPlatform` / `enableTestDummy`）
- 说明书的数值是写死的文本，改完配置后如需同步可自行编辑 `assets/bscoins/patchouli_books/guide/*/entries/*.json`
